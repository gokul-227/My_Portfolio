Taleo New Hire – HCM Migration

Automating onboarding processes by migrating Taleo New Hire data to Oracle HCM via scalable AWS data pipelines, replacing manual CSV-based processes.

Project Information

  • Project: Taleo New Hire – HCM Migration
  • Client: Worley, Australia
  • Company: Perficient, Bangalore, India
  • Duration: Apr 2025 – Present
  • Domain: Human Capital Management / HR Automation
  • Access: Enterprise Confidential

Project Overview

The project automated the onboarding process by migrating Taleo New Hire data to Oracle HCM. Legacy manual workflows using CSV files were replaced with an AWS-based pipeline, ensuring validation, transformation, mapping to HCM JSON structures, and API-driven onboarding for Worker and Salary data.

Key Features

  • End-to-end automation of Taleo New Hire onboarding
  • Data ingestion from SMB network drives to AWS S3
  • Data validation, transformation, and mapping using PySpark
  • Integration with Oracle HCM Worker and Salary APIs
  • Error handling and failure notifications using AWS SNS
  • Workflow orchestration via Airflow for sequential processing
  • Reusable and parameterized Glue jobs using YAML templates
  • Infrastructure provisioning and CI/CD using Terraform, Jenkins, and CodePipeline
  • Excel-based logging and auditing for compliance

Technologies Used

Cloud: AWS (Glue, S3, Lambda, SNS, DynamoDB, Airflow)
Processing: PySpark, Python
Database / File Systems: SMB network drives, Oracle HCM
DevOps / CI/CD: Terraform, GitHub, Jenkins, CodePipeline
Tools: YAML templates, Excel for validation, JIRA

Architecture Highlights

  • SMB-based Taleo CSV data ingestion into AWS S3
  • Data transformations and mapping to HCM JSON structures using Glue PySpark jobs
  • Validation and error-handling mechanisms with dynamic notifications via SNS
  • Workflow orchestration with Airflow to ensure sequential execution of tasks
  • Logging and auditing using Excel-based reports, DynamoDB, and CloudWatch
  • Automated deployment and provisioning with Terraform, Jenkins, and CodePipeline

  • Challenge: Scalable and reusable deployment across environments

Impact & Outcome
