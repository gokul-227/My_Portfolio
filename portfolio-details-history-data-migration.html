History Data Migration (Mainframe to AWS)

A large-scale enterprise data migration initiative transforming legacy mainframe data into a modern AWS-based analytics platform for Blue Cross Blue Shield of Massachusetts.

  2. Project Details

Project Information

  • Project: History Data Migration (Mainframe to AWS)
  • Company: IBM, Bangalore, India
  • Client: Blue Cross Blue Shield of Massachusetts
  • Duration: Apr 2019 – Oct 2021
  • Access: Restricted (Enterprise Project)

Project Overview

This project focused on migrating large volumes of historical healthcare data from legacy mainframe systems into AWS cloud infrastructure. The goal was to modernize data storage, improve accessibility, and enable advanced analytics capabilities.

Due to enterprise confidentiality, detailed code and datasets cannot be shared. However, this overview highlights the architecture, tools, and contributions involved in delivering a successful migration.

Project Description

Blue Cross Blue Shield of Massachusetts is a leading healthcare insurance provider offering comprehensive services across the state. The organization manages complex Host & Home plans, requiring robust data handling capabilities.

This initiative involved extracting historical datasets from Mainframe systems (VSAM, DB2), transforming them using Syncsort ETL processes, and loading them into AWS S3. The migrated data was then structured into Athena tables to support reporting, analytics, and business intelligence.

Key Features

  • End-to-end migration from Mainframe (VSAM/DB2) to AWS cloud
  • High-volume batch processing using Syncsort (DMExpress)
  • Structured data transformation into CSV format for cloud ingestion
  • Secure and scalable storage using AWS S3
  • Query and analytics layer using AWS Athena
  • Comprehensive data validation and reconciliation framework
  • Documentation-driven development and mapping strategy

Technologies Used

Mainframe: JCL, VSAM, COBOL, DB2
ETL Tool: Syncsort DMExpress
AWS: Amazon S3, AWS Glue, Athena

Architecture Highlights

  • Source data extracted from Mainframe using JCL jobs and COBOL programs
  • ETL transformations handled via Syncsort with business rule enforcement
  • Processed data stored in AWS S3 buckets in structured CSV format
  • Athena tables created for querying and downstream analytics
  • Validation pipelines ensured data integrity across systems

Roles & Responsibilities

  • Analyzed legacy Mainframe datasets and job workflows for migration readiness
  • Prepared Master Mapping Documents including file layouts and copybooks
  • Developed ETL jobs using Syncsort with advanced filtering and transformation logic
  • Executed data extraction and conversion into cloud-compatible formats
  • Led User Acceptance Testing (UAT) to validate data integrity and completeness
  • Created and managed AWS S3 buckets for scalable storage
  • Designed Athena tables and executed analytical queries
  • Authored detailed technical and design documentation
  • Conducted client walkthroughs and post-migration reviews
  • Collaborated with cross-functional teams to improve data quality and performance

Challenges & Solutions

  • Challenge: Handling complex legacy data formats and copybooks
    Solution: Created detailed mapping documents and transformation rules
  • Challenge: Ensuring data accuracy across large datasets
    Solution: Implemented multi-level validation and reconciliation checks
  • Challenge: Migrating high-volume batch data efficiently
    Solution: Optimized Syncsort jobs and parallel processing strategies

Impact & Outcome

  • Successfully migrated critical historical healthcare data to AWS
  • Enabled faster data access and analytics using Athena
  • Reduced dependency on legacy Mainframe systems
  • Improved data transparency and reporting capabilities
  • Established a scalable foundation for future cloud modernization initiatives
