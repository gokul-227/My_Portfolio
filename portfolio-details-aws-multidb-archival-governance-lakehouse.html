Project Overview

ArchiveLake is a centralized archival platform that allows users to connect to multiple databases, select tables, and archive historical data into a governed AWS data lake.

It combines a modern React frontend with a fully serverless AWS backend to deliver scalable, secure, and automated archival workflows with real-time query capabilities.

Project Description

ArchiveLake is designed to solve the challenges of growing databases by offloading cold and historical data into cost-efficient cloud storage while maintaining full accessibility and governance.

The platform supports multiple relational and NoSQL databases, enabling organizations to centralize archival operations and enforce consistent data governance policies.

Key Features

  • Multi-database connectivity (PostgreSQL, MySQL, Oracle, SQL Server)
  • Centralized archival into AWS S3 (Iceberg format)
  • Automated validation (row count, schema, checksum)
  • Secure authentication using Amazon Cognito
  • Real-time job tracking and audit logs
  • Interactive UI for managing archival workflows
  • Direct querying using Amazon Athena
  • Encryption using AWS KMS

Architecture Components

  • Frontend – React + TypeScript dashboard
  • CloudFront + S3 – Static hosting and CDN
  • Cognito – Authentication and user management
  • API Gateway – REST API layer
  • Lambda – Business logic and orchestration triggers
  • DynamoDB – Stores configurations and logs
  • Step Functions – Workflow orchestration
  • Glue – ETL processing using PySpark
  • S3 – Data lake storage
  • Athena – Query engine for archived data
  • KMS – Encryption and security

Workflow Execution

  • User logs in via Cognito-secured web application
  • Database connections are configured and stored in DynamoDB
  • User selects tables and defines archival rules
  • Lambda triggers Step Functions workflow
  • Glue jobs extract and archive data into S3 Iceberg tables
  • Validation jobs verify data integrity
  • Users query archived data using Athena

Deployment Strategy

The platform is deployed using Terraform and automated shell scripts, provisioning both backend infrastructure and frontend hosting in a single workflow. 

./scripts/deploy.sh your-email@example.com

Key Advantages

  • Fully serverless and highly scalable
  • Reduces database storage costs significantly
  • Maintains full query capability using Athena
  • Provides strong governance and auditability

Impact

  • Centralizes enterprise archival strategy
  • Improves database performance by offloading cold data
  • Enhances compliance with validation and audit logging
  • Provides a unified platform for data archival and analytics
