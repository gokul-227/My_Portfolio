Project Overview

Archive-IO is an AWS-based automated archival and validation platform that enables seamless migration of data from relational databases into a scalable data lake using Athena Iceberg tables.

The platform is fully Infrastructure-as-Code (Terraform-driven) and supports orchestration, validation, reporting, and governance with minimal manual effort.

Project Description

Archive-IO provides an end-to-end automated workflow for archiving structured data from RDBMS systems into AWS. It integrates multiple AWS services to create a scalable, secure, and highly observable pipeline.

The system ensures data integrity through validation pipelines and produces audit-ready reports, making it suitable for enterprise governance, compliance, and long-term storage.

Key Features

  • API-driven archival workflow using API Gateway
  • Step Functions orchestration for workflow automation
  • Glue-based ETL jobs for archival, validation, and purge
  • Automated validation (schema, row count, checksum)
  • PDF report generation via Lambda
  • Metadata tracking using DynamoDB
  • Centralized logging using CloudWatch
  • Environment-based deployments (dev, qa, prod)

Architecture Components

  • API Gateway – Entry point for triggering workflows
  • Step Functions – Orchestrates archival pipeline
  • Glue Jobs – Handles ETL processing
  • Lambda – Workflow trigger & reporting
  • S3 – Stores archived data and reports
  • DynamoDB – Stores metadata and execution logs
  • IAM – Provides secure role-based access
  • CloudWatch – Monitoring and logging

Workflow Execution

  • User triggers API Gateway endpoint with payload
  • Step Functions orchestrates the pipeline
  • Glue archival job moves data into Iceberg tables
  • Validation job ensures data accuracy
  • Lambda generates PDF reports
  • Results stored in S3 and metadata updated in DynamoDB

Deployment Strategy

The entire infrastructure is provisioned using Terraform with environment-specific configurations (dev, qa, prod). Deployment is automated using shell scripts. 

cd terraform_scripts
./deploy.sh dev

Sample Input Payload

{
  "glue_connection": "postgres_connection",
  "legal_hold": false,
  "retention_policy": 6,
  "source_database": "postgres_databse_eeql",
  "source_schema": "postgres_test_schema",
  "source_table": [
    {
      "table_name": "products",
      "condition": "Index < 20"
    }
  ],
  "triggered_by": "Gokul"
}

Outputs

  • S3 – Archived datasets and PDF reports
  • DynamoDB – Metadata and execution tracking
  • CloudWatch – Logs and monitoring
  • API Gateway – Workflow trigger endpoint

Impact

  • Automates end-to-end archival workflows
  • Improves data governance and auditability
  • Reduces manual effort and operational overhead
  • Scalable and reusable across multiple environments
