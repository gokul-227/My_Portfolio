Project Overview

The Inhouse Cloud Archival Platform is a next-generation enterprise solution designed to replace legacy archival systems such as Informatica ILM. The platform enables scalable, secure, and governed archival of large-scale enterprise data from multiple on-premise databases into AWS.

Due to enterprise confidentiality and legal restrictions, the source code and internal assets of this project cannot be shared or distributed. However, this page provides a detailed overview of the architecture, design, and contributions delivered as part of this engagement.

Project Description

This platform was built as a fully cloud-native data archival and governance system leveraging AWS services. It enables organizations to archive structured data from on-premise RDBMS systems including MySQL, PostgreSQL, Oracle, and SQL Server into AWS Athena Iceberg tables.

The solution follows a metadata-driven architecture with automated orchestration, validation pipelines, retention policy enforcement, and role-based access control. It ensures high scalability, compliance, and performance while significantly reducing operational overhead.

Key Features

  • Scalable archival of enterprise data into AWS data lake (Iceberg tables)
  • Metadata-driven orchestration and configuration
  • Automated data validation and reconciliation framework
  • Retention policy management and legal hold capabilities
  • Secure role-based access control using AWS Lake Formation
  • End-to-end audit, monitoring, and logging framework

Technologies Used

AWS Glue, PySpark, MWAA (Airflow), AWS Lambda, Amazon S3, Athena (Iceberg), DynamoDB, API Gateway, QuickSight, Lake Formation, KMS, VPC, Terraform, CloudWatch

Roles & Responsibilities

  • Designed end-to-end product architecture, data model, and orchestration framework.
  • Developed scalable AWS Glue Spark jobs to archive RDBMS data into Athena Iceberg tables with governance metadata.
  • Built dynamic Lambda-based framework for table discovery and YAML-driven execution.
  • Implemented validation pipelines for row count, schema validation, and checksum reconciliation.
  • Designed and developed Airflow DAGs (MWAA) for orchestration of archival, validation, and purge workflows.
  • Developed automated reporting solutions integrated with QuickSight dashboards and PDF exports.
  • Built centralized audit logging and configuration tracking using DynamoDB.
  • Implemented secure RBAC model using AWS Lake Formation.
  • Developed API Gateway-based services for secure data access and report downloads.
  • Designed retention lifecycle workflows including archival, update, and purge processes.
  • Configured cloud security (KMS encryption, IAM roles), networking (VPC), and monitoring (CloudWatch).
  • Led deployment across Dev, QA, and Production environments with complete documentation and testing.

Impact & Outcome

  • Replaced legacy archival system with a modern, scalable cloud-native solution
  • Improved data accessibility and query performance using Athena Iceberg
  • Reduced operational cost and manual effort through automation
  • Enabled strong governance, compliance, and audit capabilities
