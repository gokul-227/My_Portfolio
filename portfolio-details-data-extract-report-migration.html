HCM Data Extract & Report – Taleo Migration

Automated extraction and migration of HCM data to Taleo SMB with AWS Glue, Airflow, and S3.

  1. Home
  2. Project Details

Project Information

  • Project: HCM Data Extract & Report – Taleo Migration
  • Company: Perficient, Bangalore, India
  • Client: Worley, Australia
  • Duration: Apr 2025 – Present
  • Access: Restricted (Enterprise Project)

Project Overview

This project automated the extraction of reports and data files from Oracle HCM APIs and migrated them to the Taleo SMB path. Leveraging AWS Glue, Airflow, and S3, it replaced manual interventions while ensuring security, compliance, and reliability.

Key Features

  • Automated HCM data extraction and migration to Taleo SMB
  • Incremental processing and environment-based parameterization
  • Error-handling and alerting via SNS and email
  • Secure credential management via Secrets Manager & KMS
  • Workflow orchestration using Airflow and EventBridge
  • CI/CD deployment using Jenkins pipelines

Technologies Used

AWS Glue, Airflow, S3, Python, SNS, DynamoDB, Terraform, Jenkins, CodePipeline, Secrets Manager, Parameter Store, KMS

Architecture Highlights

  • DAG design in Airflow for sequential extraction and file transfer
  • Glue jobs for API data extraction and SMB delivery
  • DynamoDB for metadata, job status tracking, and audit
  • Error-handling with notifications via SNS/email
  • Secrets and KMS for secure credential handling
  • Jenkins CI/CD for automated deployments across Dev/QA/Prod

Roles & Responsibilities

  • Designed Airflow DAGs and Glue jobs for HCM data extraction and migration
  • Developed parameterized YAML templates for environment flexibility
  • Integrated DynamoDB for logging and metadata management
  • Implemented error notifications via SNS/email
  • Configured secure credentials via Secrets Manager and KMS
  • Optimized Glue jobs for incremental processing and parallel execution
  • Automated deployments with Jenkins CI/CD pipelines
  • Collaborated with onshore/offshore teams for testing, validation, and handover

Challenges & Solutions

  • Challenge: Securely handling HCM API credentials
    Solution: Used Secrets Manager & KMS for encryption and access control
  • Challenge: Reliable automated report delivery
    Solution: Implemented Airflow DAGs with error notifications and retries
  • Challenge: Incremental data extraction without manual intervention
    Solution: Developed incremental Glue jobs with parameterized YAML templates

Impact & Outcome

  • Eliminated manual HCM report extraction
  • Secured and auditable automated migration to Taleo SMB
  • Enhanced reliability, monitoring, and alerting for stakeholders
  • Enabled compliance with enterprise data handling policies
