HealthScore Card – Automated Data Pipeline on AWS

Transforming a manual Excel-based dashboard into a fully automated data pipeline with AWS, PySpark, and Athena, delivering accurate metrics to Tableau dashboards.

  2. Project Details

Project Information

  • Project: HealthScore Card – Automated Data Pipeline
  • Client: Cox, USA
  • Company: Eclerx, Bangalore, India
  • Duration: Oct 2024 – Mar 2025
  • Domain: Healthcare / Analytics
  • Access: Enterprise Confidential

Project Overview

HealthScore Card automated the manual Excel-based reporting process by integrating multiple data sources, applying complex business rules, and storing the transformed results in AWS Athena. The data was visualized in Tableau dashboards for stakeholders, eliminating manual effort and enhancing accuracy.

Key Features

  • Automation of legacy Excel-based HealthScore dashboard
  • Integration of multiple data sources: SFTP, Oracle DB, Athena tables
  • Scalable PySpark ETL jobs for complex business rule computations
  • Incremental data load with rolling 3-month history
  • Data retention automation and record purging
  • Monitoring and audit logging using DynamoDB and CloudWatch
  • Email notifications via SES for job status alerts
  • CI/CD deployment pipelines via Jenkins

Technologies Used

Cloud: AWS (Glue, Lambda, ECS Fargate, EventBridge, Athena, S3, SES, CloudWatch, DynamoDB)
Processing: PySpark, Python
Database: Oracle, Athena
DevOps: Terraform, Jenkins, Bitbucket
Tools: SQL, Tableau, JIRA

Architecture Highlights

  • Data ingestion from SFTP, Oracle, and Athena sources
  • ETL transformations using PySpark Glue jobs
  • Incremental load for latest month with 3-month rolling history
  • Job orchestration via Glue workflows and EventBridge scheduling
  • Monitoring with CloudWatch and DynamoDB logging
  • Notifications using SES for stakeholders
  • Data visualized in Tableau dashboards

Roles & Responsibilities

  • Requirement analysis and designing data pipeline architecture
  • Evaluated AWS Glue, ECS Fargate, and Lambda through POCs
  • Developed Terraform scripts for provisioning across Dev, QA, and Prod
  • Implemented Athena-based data models for efficient storage
  • Developed PySpark ETL jobs to replace manual Excel formulas
  • Designed incremental load and rolling 3-month history process
  • Implemented automated data purging using Python scripts
  • Set up job logging framework using DynamoDB and CloudWatch
  • Configured SES notifications for job completion and alerts
  • Built Glue workflows with crawlers and triggers for orchestration

  • Participated in code reviews and onshore knowledge transfer sessions

Challenges & Solutions

  • Challenge: Migrating complex Excel calculations to scalable ETL
    Solution: PySpark transformations replacing Excel formulas
  • Challenge: Maintaining incremental data loads with rolling history
    Solution: Custom incremental load scripts with 3-month retention
  • Challenge: Real-time monitoring and alerting
    Solution: CloudWatch & DynamoDB logging with SES notifications

Impact & Outcome

  • Eliminated manual Excel-based processing
  • Improved accuracy and reliability of HealthScore metrics
  • Reduced manual efforts and turnaround time for reporting
  • Enabled fully automated, auditable, and scalable data pipeline
  • Stakeholders receive timely, accurate dashboards for decision-making
