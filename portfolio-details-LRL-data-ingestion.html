LRL Learning & Development – Data Ingestion

A cloud-based data ingestion and transformation pipeline designed to modernize legacy learning systems by consolidating multi-source data into a unified, structured Postgres database.

Project Information

  • Project: LRL Learning & Development – Data Ingestion
  • Company: Aligned Automation, Bangalore, India
  • Client: Lilly, USA
  • Duration: Aug 2022 – Mar 2023
  • Access: Enterprise (Confidential)

Project Overview

This project focused on building a scalable data ingestion pipeline to consolidate learning and development data from multiple sources into a centralized PostgreSQL database.

The solution followed EDB data layering principles (Raw → Refined → Conformed), enabling structured data processing, analytics, and API-based data access.

Project Description

The LRL application is a legacy learning system used for managing course and training data. This project modernized its data architecture by ingesting data from Excel, CSV files, and PostgreSQL databases into a unified cloud-based system.

Using AWS services and PySpark, raw data was cleansed, transformed, and structured into refined and conformed layers, ensuring high data quality and consistency across systems.

Key Features

  • Multi-source data ingestion (Excel, CSV, PostgreSQL)
  • Layered architecture: Raw → Refined → Conformed
  • Serverless data pipeline using AWS services
  • Automated event-driven processing using EventBridge
  • API layer for data access from conformed database
  • Secure and scalable cloud infrastructure

Technologies Used

Cloud: AWS (S3, Lambda, Glue, EventBridge, RDS)
Processing: PySpark, Python
Database: PostgreSQL (RDS)
DevOps: GitHub, CodePipeline, CloudFormation (YAML)
Tools: SQL, JIRA

Architecture Highlights

  • Raw data ingested into S3 via file uploads and database extraction
  • EventBridge triggers Lambda functions on file upload events
  • Lambda functions initiate Glue ETL jobs
  • PySpark scripts transform raw data into refined PostgreSQL tables
  • Business logic applied to create conformed data layer
  • Serverless API exposes conformed data for end users
