Project Overview

LakeChat AI is a conversational analytics platform that allows users to interact with data lakes using natural language instead of writing SQL queries.

It bridges the gap between business users and data by combining AI-driven query generation with serverless data processing and visualization.

Project Description

LakeChat AI transforms traditional data analytics by enabling users to ask questions in plain English and automatically translating them into optimized SQL queries.

The system integrates a rule-based AI engine with AWS services to provide a fully serverless, scalable, and cost-efficient analytics platform with built-in visualization capabilities.

Key Features

  • Natural language to SQL (NL→SQL) query generation
  • Dataset upload (CSV, JSON, Parquet)
  • Automatic schema detection and cataloging
  • Serverless SQL execution using Athena
  • Smart chart recommendations (bar, line, pie)
  • Interactive dashboard with real-time visualizations
  • Query history tracking and performance metrics
  • Dataset browser with preview capabilities
  • Transparent SQL generation for every query

Architecture Components

  • Frontend – React + Tailwind UI
  • S3 – Dataset storage and frontend hosting
  • API Gateway – Backend API routing
  • Lambda – FastAPI backend execution
  • AI Engine – Rule-based NL→SQL generator
  • Athena – SQL query execution engine
  • Glue Catalog – Metadata and schema storage

Workflow Execution

  • User uploads dataset via web interface
  • File is stored in S3 and cataloged in Glue
  • User submits a natural language query
  • AI engine converts query into SQL
  • Athena executes SQL on data lake
  • Results returned and visualized automatically
