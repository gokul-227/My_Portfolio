Project Overview

This platform enables organizations to upload, validate, and archive flat files into a modern AWS-based data lake, making historical data instantly queryable.

It combines a user-friendly frontend with a powerful serverless backend to provide secure ingestion, automated validation, and real-time analytics.

Project Description

The AWS Flat File Archival Lakehouse is designed to modernize legacy data storage systems by enabling seamless ingestion of CSV, Excel, and Parquet files into a centralized data lake.

The platform ensures data quality through validation checks and automates the entire ingestion pipeline using AWS Step Functions and Glue, making it scalable, secure, and production-ready.

Key Features

  • Drag-and-drop file upload (CSV, Excel, Parquet)
  • Pre-ingestion validation (schema, row count, data quality)
  • Serverless workflow orchestration using Step Functions
  • Automated ETL processing using AWS Glue (PySpark)
  • Real-time job tracking and monitoring
  • Query archived data instantly using Athena
  • Secure authentication using Amazon Cognito
  • Audit logging with DynamoDB
  • Notifications using SNS

Architecture Components

  • Frontend – React + TypeScript dashboard
  • CloudFront + S3 – Static website hosting
  • Cognito – User authentication and authorization
  • API Gateway – Backend API layer
  • Lambda – Business logic and validation
  • Step Functions – Workflow orchestration
  • Glue – ETL processing and transformation
  • S3 – Data lake storage (raw + curated)
  • Athena – SQL query engine
  • DynamoDB – Metadata and audit logs
  • SNS – Notifications and alerts

Workflow Execution

  • User uploads file via web interface
  • File is validated for schema and quality checks
  • Validated file is uploaded to S3
  • Step Functions orchestrates ingestion pipeline
  • Glue ETL job processes and stores data in Iceberg tables
  • Metadata is recorded in DynamoDB
  • User queries data using Athena dashboard

Deployment Strategy

The entire platform is deployed using Terraform and automated scripts. It provisions both backend infrastructure and frontend hosting in a single workflow.
