Eightfold – HCM & Taleo Integration

Automating onboarding processes by migrating Taleo New Hire data to Oracle HCM via scalable AWS data pipelines, replacing manual CSV-based processes.

  1. Home
  2. Project Details

Project Information

  • Project: Eightfold – HCM & Taleo Integration
  • Company: Perficient, Bangalore, India
  • Client: Worley, Australia
  • Duration: Apr 2025 – Present
  • Access: Restricted (Enterprise Project)

Project Overview

This project modernized the recruitment integration process by introducing an AWS-based middleware layer between the Eightfold job portal and Oracle HCM/Taleo systems. The solution provided secure, auditable, and streamlined access for recruitment data integration and API governance.

Key Features

  • AWS-based middleware layer for secure integration
  • API Gateway & Lambda microservices to handle HCM/Taleo endpoints
  • Endpoint-level and parameter-level access control
  • DynamoDB metadata store for managing endpoints and logs
  • Error-handling, logging, and monitoring via CloudWatch
  • CI/CD deployment via Jenkins and Terraform infrastructure automation

Technologies Used

AWS, API Gateway, Lambda, DynamoDB, Python, Terraform, GitLab, Jenkins, CodePipeline, Postman, KMS, OAuth, Basic Auth

Architecture Highlights

  • Eightfold portal requests routed via API Gateway to Lambda services
  • Lambdas connect securely to HCM and Taleo endpoints
  • Metadata and job logs stored in DynamoDB
  • CloudWatch integrated for monitoring, alerting, and troubleshooting
  • Terraform used for provisioning resources across Dev/QA/Prod

Roles & Responsibilities

  • Designed API Gateway-Lambda architecture for secure HCM/Taleo integrations
  • Developed Lambda microservices to fetch and transform data from endpoints
  • Implemented authentication using OAuth 2.0 for HCM and Basic Auth for Taleo
  • Created DynamoDB metadata store and Lambda authorizers for endpoint management
  • Deployed Terraform infrastructure and automated CI/CD with Jenkins
  • Implemented error handling, logging, and CloudWatch monitoring
  • Collaborated with Eightfold and Worley teams for testing and validation

Challenges & Solutions

  • Challenge: Secure and controlled access to multiple endpoints
    Solution: Created Lambda authorizers and parameter-level filters
  • Challenge: Managing endpoint configurations across environments
    Solution: Centralized metadata store in DynamoDB
  • Challenge: Auditable and reliable data integration
    Solution: Implemented logging, error-handling, and CloudWatch alerts

Impact & Outcome

  • Streamlined recruitment integration process with enhanced security
  • Reduced manual intervention for HCM-Taleo data exchange
  • Centralized configuration and logging for maintainability
  • Enabled faster troubleshooting and operational efficiency
